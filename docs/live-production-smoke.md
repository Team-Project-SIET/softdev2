## Controlled port-release diagnosis after attempt #5

Attempt #5's exact socket state cannot be recovered because the harness overwrote its first port snapshot and did not label the failed bind iteration. The assertion itself had a concrete semantic flaw: it treated `EADDRINUSE` from an IPv4 `SO_REUSEADDR` bind as proof that the OpenTTD listener remained. A controlled accepted TCP connection with a non-`SO_REUSEADDR` listener reproduces `EADDRINUSE` after that listener closes while the endpoint is in `TIME_WAIT`; there is no `LISTEN` socket. An unrelated process can also claim a released dynamic port before a probe. Neither condition proves an owned listener leak. These controlled findings explain the ambiguity, but do **not** establish which condition caused attempt #5.

The T17 harness now uses a Linux `/proc` endpoint probe for the configured IPv4 loopback game TCP/UDP and Admin TCP sockets. It records each role, port, AF_INET address, errno, observed TCP states, owner PIDs/process groups, elapsed time, and whether process ownership checks passed. It checks for an owned listener or bound UDP socket using socket inodes and the OpenTTD process group, with one monotonic one-second deadline. It treats a bind blocked without a listener as separate evidence, not as an owned leak; an unrelated rebinder is identified and reported separately. Unattributed bound sockets and owned listeners fail after the deadline. IPv6 wildcard and IPv4-mapped sockets are included where they could cover the IPv4 endpoint. The probe closes each temporary socket. A port-evidence JSON file is written on either result, and the database summary retains the actual assigned ports instead of overwriting them. No production runner code changed. The existing `test_forced_stop_signals_only_owned_group_before_lease_release` verifies reap before lease close, and the new controlled normal-completion test verifies both game protocols and Admin after runner cleanup.

Controlled tests cover free endpoints, game TCP/UDP and Admin leak detection, exact role/port diagnostics, listener close with bounded polling, `TIME_WAIT` after close, unrelated process rebind, dual-stack wildcard coverage, and probe descriptor closure. Focused runner/T13/T16/harness-controlled regressions, the full ordinary suite, Ruff, format, production-file `ty`, and `git diff --check` passed after the correction.
